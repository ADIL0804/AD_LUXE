# AD_LUXE Gestion

Application web autonome pour suivre les articles, variantes (taille/couleur), stocks, achats, ventes et dépenses de la boutique.

## Utilisation

Ouvre `index.html` dans un navigateur ou héberge ce dossier comme page statique. L'application peut aussi être publiée sur GitHub Pages si le dépôt est configuré pour cela.

## Données

Les données sont enregistrées dans le stockage local du navigateur sur l'appareil. Elles ne sont pas envoyées à GitHub. Utilise **Réglages & sauvegarde** pour exporter régulièrement une sauvegarde JSON et la restaurer sur un autre appareil.

## Modification

L'interface, le style et la logique sont dans le fichier autonome `index.html`.
